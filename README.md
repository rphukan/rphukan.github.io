# Running on local for authoring and testing
The hugo server command builds your site and serves your pages using a minimal HTTP server. When you run hugo server it will display the URL of your local site:
```shell
hugo server
```

You can run the Hugo server to include the draft contents
```shell
hugo server -D
```
OR
```shell
hugo server --buildDrafts
```
By default the server starts on [http://localhost:1313/](http://localhost:1313/)
